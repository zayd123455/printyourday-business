# How this site is built

- Start every answer with "Zayd".
- Static site only: HTML, CSS, and a little plain JavaScript if a page truly needs
  it. No frameworks, no build step, no npm, no server.
- If a request needs a server, a database, logins, payments or a form that saves
  data, stop and tell me, then add it to the Later list in PRD.md.
- Styles live in css/styles.css. Use only the custom properties in its :root block.
- Build only the pages listed in PRD.md. Ask before adding a page or a section.
- Never mention EastCoast MuralPros. The phone number is the key action, keep it in
  the header of every page.
- File and folder names: lowercase, hyphens, no spaces.
